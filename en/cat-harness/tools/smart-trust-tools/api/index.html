SMART Trust HCERT library tools

The Tools of smart-trust-tools, in the two forms other tools read:

  • openapi.json — OpenAPI 3.1.0, one operation per Tool. Open it in Swagger UI or Redoc, or generate a client from it. The paths are the Tools’ call contracts, not HTTP endpoints: each operation’s x-invoke says how the Tool is really reached.
  • mcp-tools.json — the answer an MCP server gives to tools/list: each tool’s name, description and input schema, read from the registrar that serves it.
